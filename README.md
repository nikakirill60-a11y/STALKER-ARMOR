# STALKER Armor — мод брони для Minecraft 1.20.1 (Forge)

Броня из S.T.A.L.K.E.R. **в один слот**: надеваешь куртку в слот нагрудника —
одет весь костюм (шлем, куртка, штаны, ботинки), каждая часть следует за
анимациями тела (ходьба, присед, поворот головы).

![](docs/preview.png)

## Что в моде (v1.2.0)
Модель куртки — **своя, из OBJ** (смоделирована поверх `steve.obj`), 7 вариантов
расцветки по группировкам:

| Предмет | Расцветка |
|---|---|
| Куртка (бандиты) | бандиты |
| Куртка («Чистое небо») | ЧН |
| Куртка («Долг») | долг |
| Куртка («Свобода») | свобода |
| Куртка (ренегаты) | ренегаты |
| Куртка (сталкер) | нейтральная |
| Куртка (сталкер Mk.II) | нейтральная Mk.II |

Все есть в креативной вкладке «Броня сталкера» и крафтятся из кожи
(шаблон нагрудника: `X X / XXX / XXX`).

## Установка
1. Minecraft 1.20.1 + Forge 47.x
2. `stalkerarmor-1.20.1.jar` → в папку `mods`

## Как добавить свою броню (формат «один OBJ — один слот»)
1. Открой **`steve.obj`** (в корне репозитория / в файлах релиза) в Blender —
   это модель игрока в нужных координатах (1 юнит = 4 пикселя MC, Y вверх,
   −Z = лицо, ноги на y=0).
2. Смоделируй броню поверх манекена, разложи по объектам:
   `head`, `chest`, `armL`, `armR`, `legL`, `legR`
   (или просто `arm`/`leg` — правая сторона отзеркалится).
3. Экспорт: File → Export → Wavefront (.obj), настройки по умолчанию.
4. Файл → `src/main/resources/assets/stalkerarmor/geo/sets/<имя>.obj`,
   текстура → `.../textures/armor/`, иконка → `.../textures/item/`,
   строка в `StalkerFullSet.java` (id, модель, текстура, тир).

Исходники автора брони: модель в `model/`, текстуры в `tex/`, иконки в `icon/`.

## Сборка
```bash
gradle build   # JDK 17, Gradle 8.1+
```
Готовый jar: `build/reobfJar/output.jar`. CI собирает при каждом пуше и
выкладывает в [Releases](https://github.com/nikakirill60-a11y/STALKER-ARMOR/releases).
